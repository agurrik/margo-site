Privacy Policy

Last updated: 8 November 2026

This policy covers "Margo uploader", the private tool the Margo Figured It Out channel uses to manage its own YouTube channel through the YouTube Data API.

Who uses it

Only the channel's owner. The tool is not offered to the public, and nobody else can sign in to it.

What it accesses

With the owner's permission (Google OAuth), the tool uploads and schedules videos, sets thumbnails and captions, manages playlists, and posts and pins comments on the channel's own videos. It reads basic statistics for those videos.

What it stores

The sign-in token is stored only on the owner's own computer. The tool does not collect, store, sell or share personal data about viewers or anyone else, and it does not use Google user data for advertising.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: leave a comment on any video at youtube.com/@margofiguredit.
